Switch between the terminal and the Agent view with a swipe on a phone in a connected session: swipe from the right edge toward the left to show the Agent view, and while it is shown swipe from the centre toward the right to return to the terminal. The two views slide as one page that follows the finger and settles on release; a short or interrupted swipe leaves the view unchanged. The swipe never starts while typing or editing text, nor inside horizontally scrollable content such as code blocks, diffs and tables. The Terminal | Agent buttons stay, and the choice is still remembered per saved host and multiplexer target.
