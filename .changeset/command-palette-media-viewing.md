Extend the Ctrl/Cmd+K palette into a keyboard-operable command palette over hosts, open sessions, workspace tools and application actions, also opened by Ctrl/Cmd+Shift+P from a focused terminal. Files previews PNG, JPEG, GIF and WebP images up to 2 MiB, shows SVG only as an image from a blob URL so its scripts never run, and renders Markdown through the Chat renderer without raw HTML, links or remote images.
