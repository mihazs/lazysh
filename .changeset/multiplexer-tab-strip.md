Add a native tab strip above the terminal for Herdr, Zellij and tmux tabs, with a Herdr workspace switcher, agent state dots, a **+** for new tabs, long-press rename for Herdr tabs and workspaces and tmux windows, and a Show tab strip setting (Auto, Always, Never). On phones it is on by default for a multiplexer session with more than one tab.
