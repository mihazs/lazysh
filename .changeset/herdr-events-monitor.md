Follow the Herdr event stream of each connected host for the inbox while no Herdr view is shown, sharing the stream a visible Herdr view reads, so a blocked or finished Herdr agent becomes an inbox event and a notification whichever page is open, deduplicated against the same turn reported by a hook, and closing the stream when monitoring is turned off or the host disconnects.
