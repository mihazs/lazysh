# Roadmap

The [lazysh GitHub Project](https://github.com/users/mihazs/projects/2) is the live roadmap. Filter by **Roadmap area** and use **Status** to follow progress; linked issues define acceptance and platform verification. The project is private, so access requires membership.

The public [delivery epic](https://github.com/mihazs/lazysh/issues/1) links the main feature issues and acceptance gates for readers without project access. No release dates are promised.
