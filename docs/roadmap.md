# Public roadmap

Start with the public [delivery epic](https://github.com/mihazs/lazysh/issues/1),
which links feature issues and their acceptance criteria. Open issues describe
remaining work; merged code is not proof of release publication or full native
parity. See [installation and acceptance status](install-and-update.md) for the
current distribution limits. No release dates are promised.

The [parity matrix](reference/parity-matrix.md) records verified reference-client behaviors per platform and links each gap to its issue.

The [Agent view specification](agent-view.md) describes the planned native view of a running agent that co-exists with its terminal.

The [local workspace specification](local-workspace.md) describes how desktop local sessions on Linux and Windows gain every feature remote sessions offer.

The [multiplexer compatibility specification](multiplexer-compatibility.md) describes the planned capability checklist for tmux, Zellij, Herdr and rmux.

Anyone can follow the public issues or propose a focused contribution without
private project access. Maintainers also use the private
[GitHub Project](https://github.com/users/mihazs/projects/2) to coordinate work;
its notes and membership are not required for public participation.
