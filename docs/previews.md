# Preview a host development server

Connect to a host, choose **Preview**, and enter the port of your HTTP development server. Choose IPv4 for `127.0.0.1` or IPv6 for `::1`, then select **Open preview**. **Discover listeners** reads the host's `ss` or `lsof` output; these are TCP listeners. Selecting a listener fills in the address and port and still requires confirmation.

Discovery shows process names and PIDs where the host exposes them. Set **Discover ports** to `all`, `none`, or a list such as `3000,8000-8010`; this filter is remembered on the device and accepts at most 1024 ports. Opening a manually entered port is still an explicit action.

HTTP checking is off by default. Enable **Check for HTTP on discovery**, then select **Discover listeners** to send a `HEAD /` request over SSH to each filtered listener. Probing is limited to 256 listeners, sixteen simultaneous channels, and a 1.5-second timeout per listener. **HTTP** means a recognizable HTTP status line was received; **No HTTP response** can mean a non-HTTP service, blocked forwarding, timeout, or an unavailable listener. There are no background scans. Keep a narrow port filter when you do not want requests sent to unrelated local services.

The native client opens an SSH `direct-tcpip` channel to the selected host loopback address. It binds only device `127.0.0.1`, preferring the selected port and falling back to a free port when occupied. There is no public tunnel or third-party service. HTTP and WebSocket traffic use the same byte-transparent forwarding path. Other local processes on the device can access the loopback listener while it is open.

Each SSH session can keep four forwards open, with sixteen total and sixteen simultaneous sockets per forward. Closing a preview waits for its worker to close the listener and active sockets. Disconnecting SSH, a remote terminal exit, or a failed SSH connection requests the same cleanup asynchronously; the session command does not wait for every preview worker. Switching app views preserves forwards until explicitly closed or the session ends. Opening an upstream channel times out after fifteen seconds; individual connections have a one-hour lifetime to bound abandoned WebSockets.

The page runs in a sandboxed iframe on a separate loopback origin. Its sandbox permits scripts, forms, and its own same-origin resources; it cannot navigate the parent window or open popups. The app grants native permissions only to its bundled local origin and main window, following [Tauri's capability boundary](https://v2.tauri.app/security/capabilities/). Remote pages receive no Tauri command permissions. The parent allows frames only from `http://127.0.0.1` and never inserts preview HTML into the app document.

Android release builds use a [network security configuration](https://developer.android.com/privacy-and-security/security-config) that permits cleartext HTTP only to `127.0.0.1`; debug builds retain development-server HTTP support. The Apple Info.plist adds an [ATS exception](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsexceptiondomains) for only `127.0.0.1`, including the IP-address exception supported since iOS 17/macOS 14. Actual Android WebView and iOS ATS behavior still require device testing. A server's framing policy, absolute URLs pointing to a different host/port, and HTTPS-only requirements can prevent display. Prefer development servers that support a reverse proxy or the displayed loopback URL.

To leave a review note, enter a page path, optional element selector, and comment, then select **Stage note in prompt**. This fills the existing prompt draft for that SSH session and leaves sending to the user. It does not inspect the page DOM or inject page JavaScript.

This implements explicit host forwarding and a browser surface from the [Moshi preview behavior](https://getmoshi.app/docs/browser-preview). Framework recognition, automatic visual element selection, and simulator streaming remain separate parity work. No full preview or native-device parity is claimed by these tests.
