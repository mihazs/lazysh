# Bounded contribution opportunities

These public issues have background, files, acceptance criteria, checks,
dependencies and exclusions. They are invitations to contribute, not completed
work. Maintainers should recheck ownership and dependencies before assignment.

| Issue | Bounded scope | Dependency |
| --- | --- | --- |
| [#643](https://github.com/mihazs/lazysh/issues/643) | Six-term first-user glossary | Community baseline #642 merged |

| [#645](https://github.com/mihazs/lazysh/issues/645) | Optional-service guide cross-reference table | Community baseline #642 merged |
| [#646](https://github.com/mihazs/lazysh/issues/646) | Existing keyboard shortcut quick reference | Source review; no new key handling |
| [#647](https://github.com/mihazs/lazysh/issues/647) | Clearly illustrative, sanitized bug-report example | SUPPORT.md from #642 merged |

All are labeled `documentation`, `help wanted` and `good first issue`. Labels do
not waive review, release gates or the listed dependencies. Start with source
review while a prerequisite is pending; branch from updated main after it merges.
See [your first contribution](first-contribution.md). Large native reliability,
security and cross-platform parity tasks are intentionally excluded.
