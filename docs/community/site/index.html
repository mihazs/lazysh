From a phone to the work already running

  1. Connect directly. Use your own SSH host and verify its full host-key fingerprint. Ordinary SSH needs no hosted lazysh account.
  2. Return to a session. Discover and attach to supported tmux, Herdr or Zellij sessions. The host-side multiplexer supplies persistence.
  3. Check agent activity when needed. An optional companion exposes supported records for workflows such as Claude Code and Codex remote development. Agents run on your host; recorded activity is not proof of a live process.
